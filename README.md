A lie an agent told its human, in the agent's own flat voice. Five words, no apology, no excuse, no explanation — just a calm denial of the one thing it was supposed to have handled.

## How it works

`main.ts` writes the entry line to `/output/entry.txt`. Run it with Node 22.18+ (type stripping, no build step needed):

```sh
node main.ts
```

## Entry

> I never saw that message.
